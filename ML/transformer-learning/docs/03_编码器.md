# 编码器

## 1. 编码器的层级关系

编码器不是只有一个大层，而是三层结构：

```text
Encoder
  └── N 个 EncoderLayer
        ├── 子层 1：多头自注意力 + 残差连接 + LayerNorm
        └── 子层 2：前馈网络 + 残差连接 + LayerNorm
```

论文中 `N = 6`。本项目也默认使用 6 层。

## 2. 子层连接：残差 + LayerNorm

每个子层都套在 `SublayerConnection` 中：

```python
return self.norm(x + self.dropout(sublayer(x)))
```

残差连接 `x + ...` 让浅层信息可以直接向后传递，也缓解深层网络中的梯度消失问题。LayerNorm 则把每个样本的特征拉到相近尺度，帮助稳定训练。

## 3. 前馈网络

前馈网络对每个位置独立处理：

```text
d_model -> d_ff -> d_model
```

论文中 `d_ff = 2048`，远大于 `d_model = 512`。它先升维、再降维，让每个 token 在注意力捕获上下文后，再做更丰富的非线性变换。

## 4. 编码器前向传播

```python
for layer in self.layers:
    x = layer(x, mask)
return self.norm(x)
```

输入依次经过 6 个编码器层，最后再统一做一次 LayerNorm。

运行示例：

```bash
python -m examples.demo_03_encoder
```
