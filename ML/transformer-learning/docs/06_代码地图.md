# 代码地图

## 从数据流角度看文件

| 数据流阶段 | 文件 | 核心类/函数 |
| --- | --- | --- |
| 输入嵌入 | `src/embedding.py` | `Embedding`, `PositionalEncoding` |
| 注意力 | `src/attention.py` | `scaled_dot_product_attention`, `MultiHeadAttention` |
| 前馈网络 | `src/feedforward.py` | `FeedForward` |
| 层规范化 | `src/layer_norm.py` | `LayerNorm` |
| 残差连接 | `src/sublayer.py` | `SublayerConnection` |
| 编码器 | `src/encoder.py` | `EncoderLayer`, `Encoder` |
| 解码器 | `src/decoder.py` | `DecoderLayer`, `Decoder` |
| 输出层 | `src/generator.py` | `Generator` |
| 组装模型 | `src/model.py` | `Transformer`, `make_model` |
| 通用工具 | `src/utils.py` | `clones` |

## 从功能角度看文件

### `src/utils.py`

只有一个 `clones` 函数。它通过深拷贝生成多个相同模块，保证不同层参数独立。

### `src/embedding.py`

把 token id 变成向量，并加上位置编码。所有输入在进入编码器或解码器之前，都会经过这里。

### `src/attention.py`

最重要的文件。先实现基础注意力函数，再基于它实现多头注意力。

### `src/feedforward.py`

两层全连接网络，先升维到 `d_ff`，再降维回 `d_model`。

### `src/layer_norm.py`

手写 LayerNorm，目的是让你看清楚“均值、方差、缩放、平移”四个步骤。

### `src/sublayer.py`

封装残差连接和 LayerNorm。它是连接“裸子层”和“编码器/解码器层”之间的桥梁。

### `src/encoder.py`

先定义单个 `EncoderLayer`，再定义堆叠后的 `Encoder`。

### `src/decoder.py`

先定义单个 `DecoderLayer`，再定义堆叠后的 `Decoder`。

### `src/generator.py`

线性层 + log_softmax。

### `src/model.py`

把前面所有组件组装为完整 Transformer，并提供 `make_model` 工厂函数。

## 建议的源码阅读顺序

```text
utils.py
  -> embedding.py
  -> attention.py
  -> layer_norm.py
  -> feedforward.py
  -> sublayer.py
  -> encoder.py
  -> decoder.py
  -> generator.py
  -> model.py
```

不要从 `model.py` 开始，那样容易迷失在组装细节里。
