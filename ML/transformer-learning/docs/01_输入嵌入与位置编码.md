# 输入嵌入与位置编码

## 1. 为什么需要词嵌入

计算机不能直接理解“猫”这个汉字。常见的做法是：

1. 分词，把句子切成 token。
2. 建立词表，给每个 token 一个唯一整数索引。
3. 用 Embedding 层把整数索引映射成稠密向量。

`nn.Embedding(vocab_size, d_model)` 本质上就是一个可学习的查找表。它的权重形状是 `[vocab_size, d_model]`，输入 token id 后，返回对应的向量。

在本项目中：

```python
Embedding(1000, 512)
```

表示词表有 1000 个 token，每个 token 用 512 维向量表示。

## 2. 为什么要乘以 sqrt(d_model)

代码中：

```python
return self.embed(x) * math.sqrt(self.d_model)
```

这是为了保持数值尺度稳定。Embedding 的初始值通常比较小，乘以 `sqrt(d_model)` 后，它的幅度与后续位置编码的幅度更接近，训练时更容易收敛。

## 3. 为什么需要位置编码

RNN 按时间步串行处理，天然知道“先出现”和“后出现”。Transformer 对所有 token 同时做注意力计算，虽然并行效率高，但如果没有额外信息，`[猫, 吃, 鱼]` 和 `[鱼, 吃, 猫]` 在自注意力中可能无法被区分。

所以需要在词向量上加上一个与位置有关的编码。

## 4. 正弦位置编码公式

```text
PE(pos, 2i)   = sin(pos / 10000^(2i / d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i / d_model))
```

- `pos`：token 在序列中的位置。
- `i`：词向量维度的索引。
- `2i` 对应偶数维，`2i+1` 对应奇数维。

代码对应：

```python
pe[:, 0::2] = torch.sin(position * div_term)
pe[:, 1::2] = torch.cos(position * div_term)
```

## 5. 位置编码如何加到输入上

词嵌入输出形状是 `[batch_size, seq_len, d_model]`，位置编码也做成同样形状，然后逐元素相加：

```python
x = x + self.pe[:, : x.size(1)]
```

最后过一个 Dropout。

运行示例：

```bash
python -m examples.demo_01_input
```
