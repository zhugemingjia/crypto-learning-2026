# 注意力机制

## 1. 注意力在做什么

普通词向量是静态的，“苹果”无论在哪个句子里可能都接近同一个向量。注意力则让模型根据上下文动态调整表示：

```text
我今天吃了一个苹果。
这家公司发布了新的苹果手机。
```

两句中的“苹果”含义不同。自注意力会让“苹果”分别更多地关注“吃”或“手机”。

## 2. Query、Key、Value 的直觉

- Query：我想查询什么。
- Key：每个位置能提供什么信息。
- Value：真正要被加权汇总的内容。

一个简化的直觉：你拿着问题 Query，去和每个 Key 计算相关度，得到注意力权重，再用这些权重对 Value 加权求和。

在自注意力中，Q、K、V 都来自同一个输入，所以叫“自”注意力。

## 3. 缩点积注意力

```text
Attention(Q, K, V) = softmax(Q K^T / sqrt(d_k)) V
```

代码：

```python
scores = torch.matmul(query, key.transpose(-2, -1)) / math.sqrt(d_k)
attn_weights = F.softmax(scores, dim=-1)
return torch.matmul(attn_weights, value), attn_weights
```

除以 `sqrt(d_k)` 的原因：当 `d_k` 很大时，点积结果的方差会变大，softmax 容易进入饱和区，导致梯度变小。缩放后分数更稳定。

## 4. 掩码的作用

在解码器中，生成第 t 个词时，不能看到第 t+1 个及之后的词。做法是构造一个上三角掩码，把未来位置设为 0，并在 softmax 前把对应分数设为 `-1e9`：

```python
scores = scores.masked_fill(mask == 0, -1e9)
```

这样 softmax 后，未来位置的权重接近 0。

本项目约定：**掩码为 1 表示允许关注，掩码为 0 表示禁止关注**。注意力实现会执行 `mask == 0` 的屏蔽，因此不能把“全 0”当作真实任务中的默认掩码。

常见的因果掩码可以这样构造：

```python
seq_len = 4
tgt_mask = torch.tril(torch.ones(seq_len, seq_len)).bool()
```

如果还要屏蔽 padding，需要把“目标位置”和“被关注位置”的有效性合并到注意力所需的形状中。当前实现接收 `[batch, query_len, key_len]`，例如只屏蔽 key 侧的 padding：

```python
valid_tokens = tgt != pad_id                 # [batch, seq_len]
padding_mask = valid_tokens.unsqueeze(1)     # [batch, 1, seq_len]
causal_mask = torch.tril(
	torch.ones(seq_len, seq_len, dtype=torch.bool)
).unsqueeze(0)                                # [1, seq_len, seq_len]
tgt_mask = causal_mask & padding_mask        # [batch, seq_len, seq_len]
```

这里的 mask 会在 `MultiHeadAttention` 内部再增加 head 维度，广播成 `[batch, heads, query_len, key_len]`。

## 5. 多头注意力

单头只能从一个角度建模关系。多头把 `d_model` 拆成 `h` 个 `d_k`，让不同头在不同子空间中学习：

```text
MultiHead(Q, K, V) = Concat(head_1, ..., head_h) W^O
```

张量变化：

```text
[batch, seq, d_model]
-> [batch, seq, h, d_k]
-> [batch, h, seq, d_k]
-> 计算注意力
-> [batch, seq, h, d_k]
-> [batch, seq, d_model]
```

代码位于 `src/attention.py`。

运行示例：

```bash
python -m examples.demo_02_attention
```
