# 学习路线

Transformer 看起来复杂，是因为它把很多基础组件组合到了一起。学习时不要一上来就看整个 `Transformer` 类，而是按照数据流动的顺序逐层拆开。

## 一句话总结数据流

```text
输入 token
  -> 词嵌入
  -> 位置编码
  -> N 层编码器
  -> N 层解码器
  -> 线性层
  -> log_softmax
  -> 词表概率分布
```

## 分步学习顺序

### 1. 输入部分：词嵌入 + 位置编码

Transformer 只能处理数字，所以第一步要把单词变成向量。又因为它没有 RNN 的循环结构，所以需要额外告诉模型每个 token 的位置。

对应文件：`src/embedding.py`  
示例：`python -m examples.demo_01_input`

### 2. 注意力机制

注意力是 Transformer 的核心。先理解单头缩点积注意力，再理解多头注意力，最后理解为什么解码器要加掩码。

对应文件：`src/attention.py`  
示例：`python -m examples.demo_02_attention`

### 3. 编码器

编码器 = 多个编码器层堆叠。每个编码器层只有两个子层：多头自注意力、前馈网络。每个子层都套着“残差连接 + 层规范化”。

对应文件：`src/encoder.py`、`src/sublayer.py`、`src/feedforward.py`  
示例：`python -m examples.demo_03_encoder`

### 4. 解码器

解码器层比编码器层多一个交叉注意力子层。它有三条信息流：

1. 掩码自注意力：处理目标序列内部关系，并防止看到未来。
2. 交叉注意力：Q 来自解码器，K/V 来自编码器。
3. 前馈网络：做进一步特征加工。

对应文件：`src/decoder.py`  
示例：`python -m examples.demo_04_decoder`

### 5. 完整模型和输出层

把输入嵌入、编码器、解码器、输出层组装起来，跑一次前向传播，确认输出形状为 `[batch_size, seq_len, vocab_size]`。

对应文件：`src/model.py`、`src/generator.py`  
示例：`python -m examples.demo_05_full_model`

## 学习检查清单

- [ ] 能说出词嵌入为什么乘以 `sqrt(d_model)`。
- [ ] 能写出注意力公式，并解释 `sqrt(d_k)` 的作用。
- [ ] 能画出多头注意力中张量从 `[batch, seq, d_model]` 到 `[batch, h, seq, d_k]` 的变化。
- [ ] 能解释残差连接为什么有助于训练深层网络。
- [ ] 能说明 LayerNorm 和 BatchNorm 的区别。
- [ ] 能指出解码器中哪个注意力需要掩码，哪个注意力使用编码器输出。
- [ ] 能说明完整模型的输出为什么是 `[batch, seq, vocab_size]`。
